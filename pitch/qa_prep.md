# Вопросы жюри к CashWatch

**Питч:** 8 слайдов, 4 мин 30 с по плану. Оставшиеся 30 с — запас на переключение к демонстрации.

| Вопрос | Короткий ответ |
|---|---|
| Что будет с новым типом нарушения? | Система сначала выделяет наблюдаемые факты. Для неизвестной ситуации локальный поиск предлагает нормативный пункт как непроверенный кандидат; подтверждение требует человека. Качество на новых типах пока не измерено. |
| Почему не обучить классификатор на 40 видео? | В данных нет меток типов, а финальный набор может содержать новые типы и ракурсы. Факты, прецеденты и нормы хранятся раздельно. |
| Откуда берётся юридическая ссылка? | Для известных типов — из проверенного реестра с дословной цитатой. VLM не генерирует реквизиты акта. Для необычной ситуации результат поиска помечен как непроверенный. |
| Насколько надёжны метрики? | Это разработческая оценка на 40 обучающих видео с исключением сцены из базы прецедентов. Правила создавались на тех же данных. Независимый финальный тест ещё нужен. |
| Укладывается ли сервис в лимит? | Медиана — 52 с, максимум в измерении — 181 с на видео. Пять одновременных загрузок завершились за 244 с на тестовой машине. |
| Какие слабые случаи уже известны? | Сложные операции с деньгами, определение типа и некоторые состояния сейфа. На слайде метрик показаны 8 из 22 точных таймкодов и 11 из 22 правильных типов. |
